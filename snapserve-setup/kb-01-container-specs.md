# Container specifications

Reference data for container types Araxys books. Use this to answer questions about container size, capacity, weight limits, and which container fits a given cargo type.

## 20ft standard (dry van) — code 20GP
- Internal dimensions: 5.9m long x 2.35m wide x 2.39m high
- Capacity: 33.2 CBM
- Max payload: 28,180 kg
- Tare weight: 2,300 kg
- Use case: General dry cargo, dense/heavy loads (machinery, tiles, spices in bags)

## 40ft standard (dry van) — code 40GP
- Internal dimensions: 12.03m long x 2.35m wide x 2.39m high
- Capacity: 67.6 CBM
- Max payload: 26,700 kg
- Tare weight: 3,750 kg
- Use case: General dry cargo, high volume / low density (garments, cartons)

## 40ft high cube — code 40HC
- Internal dimensions: 12.03m long x 2.35m wide x 2.69m high
- Capacity: 76.3 CBM
- Max payload: 28,600 kg
- Tare weight: 3,900 kg
- Use case: Bulky light cargo needing extra height (furniture, textiles)

## 20ft reefer — code 20RF
- Internal dimensions: 5.44m long x 2.29m wide x 2.27m high
- Capacity: 28.3 CBM
- Max payload: 27,400 kg
- Tare weight: 3,080 kg
- Temperature range: -25C to +25C
- Use case: Temperature-controlled cargo — marine/seafood, dairy, pharma

## 40ft high cube reefer — code 40RF
- Internal dimensions: 11.56m long x 2.29m wide x 2.5m high
- Capacity: 59.3 CBM
- Max payload: 29,000 kg
- Tare weight: 4,800 kg
- Temperature range: -25C to +25C
- Use case: Temperature-controlled cargo, larger volume

## LCL (shared container / groupage) — code LCL
- Capacity: priced per unit (no fixed capacity)
- Use case: Below-container-load cargo, priced per CBM or revenue ton, consolidated with other shippers

## Choosing a container -- quick guidance for the agent
- If the customer's cargo volume is under roughly 15 CBM, LCL is usually more economical than a full container.
- If cargo needs refrigeration or temperature control at any point, always route to 20RF or 40RF, never a dry van.
- If cargo is bulky but light (furniture, textiles) and volume exceeds ~60 CBM, prefer 40HC over 40GP for the extra height.
- If unsure which container fits, ask for approximate volume (CBM) and weight (kg), then match against the capacity and max payload figures above -- never let both limits be exceeded.
